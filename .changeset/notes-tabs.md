Add All, Mine and Shared with me tabs to Notes. Mine holds the Notes you wrote, shared or not; Shared with me holds the Notes others wrote and shared with you. Every tab keeps the same order, newest edit first, and an empty tab says so, such as "Nothing shared with you yet". The tab you pick is kept in the page address, so the browser's Back button returns to it.
