Add the Notes App, with private Text notes. The Admin grants Notes access from the Accounts screen like any other App, and an Account holding it gets a Notes tile on home. Notes lists the Notes you made, newest edit first, each with its type icon, its title (or the start of its text) and when it was last edited. New → Text note opens an editor at once with a large title and a plain-text body kept exactly as typed, with no Markdown or links. Typing saves about a second after you pause, with no Save button, and "Edited … ago" shows at the foot. A new Note left with nothing typed is not kept. Delete note in the ⋯ menu removes a Note for good after a confirmation. For now each Note is seen only by the Account that made it; not even the Admin can open someone else's.
